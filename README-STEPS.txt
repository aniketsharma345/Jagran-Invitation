GITHUB PAGES - STEPS (5 min, free)

1. Sign in at github.com > New repository.
   Name: jagran   |   Public   |   Create repository.
2. Click "uploading an existing file" > drag index.html and preview.jpg > Commit changes.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder /(root) > Save.
4. Wait ~1 minute. Your link will be:
   https://aniketsharma345.github.io/Jagran-Invitation/
5. IMPORTANT: open index.html in the repo > pencil icon (edit) > replace every
   aniketsharma345 with your real GitHub username (2 places) > Commit.
   (This lets WhatsApp find the preview image.)
6. Paste the link in WhatsApp. It shows the invitation image card; tapping opens the page.
   If WhatsApp shows an old/blank preview, add ?v=2 to the end of the link and resend.
